# Dark Throne (этап 1)
Minecraft 1.16.5 / Forge 36.2.39 / Vampirism 1.9.10 / Java 8.

## Сборка (в проекте нет gradlew: это исходники, готового jar пока нет)
**Вариант 1, без установки (GitHub Actions):** залей папку проекта в репозиторий на GitHub,
открой вкладку Actions, дождись зелёной сборки и скачай артефакт `darkthrone-jar`
(внутри `darkthrone-1.0.0.jar`). Положи jar в `mods` рядом с Vampirism.

**Вариант 2, локально:** JDK 8 + Gradle 7.x (или gradle wrapper из официального MDK Forge 1.16.5),
команда `gradle build`; jar будет в `build/libs`.

Vampirism подключается через `VampirismBridge` (рефлексия), поэтому для сборки он не нужен.

## Что работает в этом этапе (не проверено в игре!)
- Король: автоматически, когда Lord 5 + все достижения `vampirism:vampire/*` (проверка раз в 2 с).
- Зов Кровавой Стаи (G, Король+), Гнев Первородного Дракона (H, Император), Кровавое Затмение (J, Император): кнопки -> пакет на сервер, перезарядка, лимиты.
- Пассивки Императора: мобы теряют цель, нет падения/огня, блок «солнечного» урона и эффектов (по имени, см. комментарий в коде), лечение и кровь за убийства.
- Ксард'Рот: 5000 HP, босс-бар, 3 фазы, текстуры по фазам, арена пока не нужна.
- Команды (оп): `/darkthrone title <игрок> <0-3>`, `/darkthrone boss`.

## Пока нет
Ритуал Императора, Кровавая Пустота (измерение), крепость, броня/оружие, анимации босса.
Все сбои связи с Vampirism пишутся в лог со словом `[DarkThrone]`.
